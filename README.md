# 鉴瓷

看馆藏瓷器的照片，按自己的等级回答。答错会收下一条知识点。另有一块只引用官方成交页的市场参考。

不登录。等级、图鉴和师徒关系记在这台设备的浏览器里。

## 怎么打开

用浏览器打开 `index.html`，或在本目录执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。手机竖屏是主布局。

## 年代怎么分段

明、清的年代题不问具体年号，只问时代风格。分段写在题目说明里：

- 明早期：洪武、永乐、宣德。正统、景泰、天顺只有著录落在这几年才归这里。
- 明中期：成化、弘治、正德。
- 明晚期：嘉靖、隆庆、万历、天启、崇祯。
- 清早期：顺治、康熙。
- 清中期：雍正、乾隆、嘉庆。嘉庆仍沿雍乾的做法，所以算中期。
- 清晚期：道光、咸丰、同治、光绪、宣统。

著录只写「明」或「清」、没有年号的，不出这道年代题。款识题仍可以问年款。

## 等级

新玩家是学徒。每一级集中看两类问题，十题一局（题量不够的一级会少一些，并写明原因）。

| 等级 | 集中看 |
| --- | --- |
| 学徒 | 款识、装饰手法 |
| 初级鉴定师 | 品种、窑口 |
| 中级鉴定师 | 年代、器型 |
| 高级鉴定师 | 底足、真伪 |

晋级要同时满足两件：这一级累计答对至少 100 题，并且这一级的正确率至少 70%。案头上能看到答对题数、正确率和还差什么。高级是最高一级。

高级题只收馆方写明了底足，或写明是仿官、仿哥的器物。照片多半不是底足特写，题面会说明这一点。没有出处的仿品不拿来充数，所以这一级题少，会重复。

## 图鉴

答错会弹出知识点：写出视觉或著录上的那一条线索，并说明为什么是这个答案。答对也会把同一条收进图鉴。图鉴可以随时再打开。

## 拜师

学徒只能拜中级鉴定师或高级鉴定师。

1. 师父在「拜师」里复制拜师帖，交给徒弟。
2. 徒弟贴上拜师帖，会有一段短的拜师礼。
3. 徒弟再答错时，弹层里会多一行师父点拨。师父也可以根据学情帖写一句指点，生成指点帖，徒弟贴回来之后，那道题会先显示这句。
4. 学徒升到初级鉴定师之后可以出师。任何一方都可以解除关系。帖子不会自动同步，对方要在自己的设备上删掉。

还没人升到中级时，可以用「看一遍拜师礼」做预演。预演师父会标明是预演，不改变正式等级。本机也可以再开一个学徒身份，方便两个人共用一台设备试帖子。

这不是社交网络，也没有账号服务器。两台设备之间靠复制帖子联系。

## 市场指导估价

案头上的「市场指导估价」按品种列出近十年（2016 年至 2026 年 11 月）能核对到的官方成交。

- 拍卖行范围本来包括苏富比、佳士得、邦瀚斯、保利、嘉德、中汉。这一版只收进了佳士得、邦瀚斯页面上写明成交价的记录。苏富比页面只看到估价，没有收。保利、嘉德、中汉没有核到可逐条打开的官方成交页，没有编造价格。
- 价格是含买方佣金的成交价。佳士得用页面上的 Price realised，邦瀚斯用 Sold for inc. premium。不是落槌价。流拍、撤拍不收。
- 人民币按世界银行当年官方汇率年均价（指标 PA.NUS.FCRF，本币兑美元）折算：外币金额 ÷ 当年该币兑美元年均价 × 当年人民币兑美元年均价。
- 时间加权：以 2026 年 11 月 20 日为基准，权重是 0.5 的（距今年数 ÷ 5）次方，大约每五年权重减半。
- 同品种价格超过中位数三倍，或不到三分之一，标成异常值，不计入加权均价，散点图里仍会画出来。
- 条数太少时界面写「样本不足」，不把两三件成交说成市场指导价。
- 清仿汝釉不是北宋汝窑，页面上会分开写。

仅供参考，不构成价值评定或投资建议。拍卖行照片没有放进仓库。

## 题库与图片

题库由 `tools/build_bank.py` 根据克利夫兰艺术博物馆 Open Access（CC0）著录生成，一共一千二百余题、近五百件器物。一件器物可以分问款识、装饰、品种、窑口、年代、器型；底足和真伪只在著录写明时才出题。年代栏出现「或」、跨两个朝代、或没有写清年款的，不出对应的题。

其中二十道是对着照片手核过的，说明写的是能看见的釉、开片、纹样或轮廓。其余题目的答案直接来自工艺栏、年代栏和品名，说明里会写「著录」。不要把这类说明当成照片里一定能看见的细节。

图片在 `images/`，由馆方网页图缩小而来，不外链。界面字体是 Noto Serif SC 与 Noto Sans SC 的子集，许可为 SIL Open Font License。

玉壶春瓶一题的馆藏英文名是 Pear-Shaped Vase。喇叭口、细颈、垂腹，在梅瓶、玉壶春瓶、天球瓶里对应玉壶春瓶。
